# adaption — школьный дневник НИШ

Оценки, журнал, табель, расписание и калькулятор СОР/СОЧ.

- Сайт: [adaption.top](https://adaption.top)
- Сообщество: [@academia_nis](https://t.me/academia_nis)
- Репозиторий: [ChQynon/123](https://github.com/ChQynon/123)

## Один интерфейс для всех платформ

`src/` — единственный источник страниц, компонентов, стилей и авторизации.
Android и iOS открывают сайт в React Native WebView; Windows и macOS — в
Electron. Вход, журнал, настройки и ПИН рисуются самим сайтом. В мобильной
оболочке больше нет отдельной копии экранов входа или блокировки.

После публикации изменений на `https://adaption.top` приложения получают их
при следующей загрузке страницы. Пересборка приложений нужна при изменениях
нативной оболочки, разрешений или зависимостей. Уже установленные старые
версии мобильной оболочки нужно один раз обновить.

Цвет страницы задаёт сайт. Он передаёт тему оболочкам для фона окна и строки
состояния. Android WebView не включает принудительное затемнение. Выбор
«Светлая / Тёмная / Системная» работает одинаково в браузере и приложениях.
Всплывающие панели не перекрашивают `body` в чёрный.

При запуске и возвращении в мобильное приложение включается тема устройства.
Ручной выбор в настройках действует до следующего входа в приложение.
Загрузка не перекрывает переходы между разделами; при сбое появляется повтор.
Сохранённые оценки и табель остаются видны, если не удалось обновить данные.

## Запуск и проверка

```sh
pnpm install
pnpm dev
pnpm exec tsc --noEmit
pnpm exec playwright install chromium webkit
pnpm test:ui
pnpm test:runtime
```

Регрессионные проверки используют тестовые данные без аккаунта СУШ:
повторное открытие/закрытие панелей, фон после перехода на вход, единый
дизайн входа и передача светлой, тёмной и системной темы в нативную оболочку.
Браузеры: Chromium для Android/десктопа и WebKit для мобильного интерфейса iOS.

## Приложения

Команды запуска, сборки и ограничения подписи — в [apps/README.md](apps/README.md).

ПИН и Face ID / Touch ID доступны только в оболочках приложений. Авторизация
использует те же cookies сайта, поэтому вход сразу действует внутри WebView.
Мобильная оболочка синхронизирует хэш ПИН и соль с Expo SecureStore;
разблокировка не сохраняется между загрузками. При сворачивании приложения
экран блокируется. На Windows используется ПИН: нативный проверяющий модуль
Windows Hello пока не реализован.

Для отображения личных данных требуется подключение к сервисам НИШ.
