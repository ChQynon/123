Исправлены зависания загрузки и замедления интерфейса. Единый дизайн сайта,
Android, iOS, Windows и macOS сохранён.

- Спиннер больше не перекрывает переходы между уже загруженными разделами.
- При сбое или превышении времени загрузки появляется кнопка повтора.
- При запуске приложения включается тема устройства; на телефоне — также
  при возвращении из фона. Ручной выбор доступен в настройках.
- Исправлена зависающая очередь обновления сессии и цикл перенаправлений
  при истёкших токенах; сетевые запросы имеют ограниченное время ожидания.
- Сохранённые оценки и табель отображаются и при ошибке обновления.
- Фон использует меньше памяти на экранах с высоким DPI, приостанавливает
  анимацию во время прокрутки и в фоне; на слабых устройствах остаётся статичным.
- Убрано размытие карточек на телефонах и сокращены задержки анимаций.
- Опубликованные изменения сайта появятся в приложениях при следующей загрузке страницы.
- Пройдены 24 проверки интерфейса Chromium/WebKit и 5 проверок загрузки/сессии.

Для исправления спиннера нужно обновить установленное приложение до 1.0.2.
Оболочки 1.0.1 не получают эти нативные изменения только через обновление сайта.

Файлы релиза:

- Windows: установщик Setup EXE и portable EXE.
- macOS: DMG и ZIP отдельно для Apple Silicon (`arm64`) и Intel (`x64`).
- Android: APK для установки вручную.
- iOS: неподписанный IPA и ZIP для симулятора Xcode.
- `SHA256SUMS.txt`: контрольные суммы скачиваемых файлов.

iOS IPA нужно подписать перед установкой на iPhone. Сертификаты Apple и
профиль распространения в этом репозитории не настроены. macOS-файлы
также выпускаются без подписи и нотариализации Apple.

На Windows используется ПИН-код; Windows Hello пока не реализован.
